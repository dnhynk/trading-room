# 트랙 C — 코인원 현물 가격 기준 메이커 (C3)

현재 실행은 `c3-rule-v2`이며 수리 감사는 `track_c/AUDIT-C3-20260905.md`다. 컨셉·통계 주장·코드 모두 감사 대상이다. C2 폐기와 C3 최초 연구는 `track_c/AUDIT-20260905.md`에 보존한다. A/B와 계약을 공유하지 않는다.

## 수익 가설과 증거의 한계

다른 거래소 가격으로 코인원 호가의 상대적 고평가를 탐지하고, 역선택이 큰 매수 대기를 거두는 메이커 전략이다. 후행 상관은 수익 증거가 아니다. 체결은 미래 경로에 의존하는 선택 사건이므로 편차가 가격 변화를 예측해도 **체결 조건부 청산 손익**은 음수일 수 있다. `dev ≥ 0`이 역선택을 제거한다는 주장은 철회한다.

9월 5일 모든 관측·테이프는 개발 표본이다. 기존 30분의 양수 결과는 추가 구간에서 재현되지 않았다. 무조건 대기가 언제나 손해라는 주장, 확정된 선행 지위·공적분·정보지분, 하루 수익률 상한도 입증되지 않았다. 현재 1만 원 실거래는 기존에 승인된 실행 표본 수집이며 양의 기대값 채택과 구분한다.

## 가격 기준 (`track_c/fair.py`)

- `M_i = (ask·bid_qty + bid·ask_qty)/(bid_qty+ask_qty)`는 **정적 잔량가중 중간가**다. 설정명 `microprice`는 호환성을 위해 유지한다. Stoikov의 전이모형 micro-price나 조건부 기댓값으로 부르지 않는다.
- 프리미엄은 과거 300초 동안 1초마다 얻은 `coinone_mid/M_i`의 중앙값이다. 현재 초를 제외하고 과거 표본 60개가 필요하다.
- `F = Σ w_i M_i r_i / Σ w_i`, `dev = (F−coinone_mid)/tick`. 기본 등가중. 명시한 가중치에 없는 거래소의 무게는 0이다. 비유한 수·음수 가중치·역순 호가를 거절한다.
- 마지막 호가가 30초 이내인 후보만 사용한다. **알려진 연결 해제는 즉시 해당 가격을 무효화**하고 재연결 후 새 호가를 요구한다. 호가 나이는 연결 생존의 증명이 아니다.
- `fairfit`은 rolling 프리미엄을 제거한 축약 회귀이며 공적분 검정·식별된 VECM이 아니다. GG/정보지분/실거래 가중치를 산출하지 않는다. 반감기는 `log(.5)/log(1+alpha_coinone−alpha_leader)`의 고정 프리미엄 AR(1) 근사로만 읽는다.

## 실행 규칙

숫자는 휴리스틱이며 이번 감사에서 수익에 맞춰 조정하지 않았다.

| 단계 | 규칙 |
|---|---|
| 종목 | BTC·ETH·XRP·SOL. 종목당 한 캠페인, 스프레드 2틱 초과 진입 없음 |
| 진입 | `dev ≥ 0`이면 최우선 매수호가에 post-only, 명목 1만 원을 수량 격자로 올림, TTL 60초 |
| 취소 | `dev < −0.5틱`, 가격 기준 불가, 실행 불가 또는 TTL 경과 |
| 부분체결 | 체결량이 고정 stop_limit에서도 최소 매도액의 105% 이상이면 잔여 매수 취소·재조회 후 확정 수량을 익절 호가에 배치. 더 작은 체결은 기존 주문 범위에서만 기다림 |
| 익절 | 진입가보다 유효 호가 1단계 위의 post-only 매도 |
| 방어 | `dev < −0.5틱`이면 익절 취소·재조회 후 확정 잔량 시장가 매도 |
| 손절 | 진입 시 유효 호가 3단계 아래로 고정. 이후 현재 tick으로 손절선을 바꾸지 않음 |
| 시간 | 첫 체결 확인 뒤 180초. 시세 상실·HALT·운영 종료도 청산 사유 |
| 잔량 | 최소 주문 미만 수량·원가·mark·평가시각을 이월. 취소 도중 체결로 작아진 잔량도 재확인. 이월은 매도 또는 승리 종료가 아님 |

현재 엔진은 익절 매도 대기 중 거래소 스탑/OCO를 함께 운용하지 않는다. 손절·방어·시간 제한은 소프트웨어 판단이다. **계획 손절액은 갭·프로세스 중단·시장가 지연 손실의 보장 상한이 아니다.** 확대 시 실행 장애에 대한 위험 구조도 평가해야 한다.

## 자본·소유권·위험

`W = 현금 + 캠페인 매수호가 평가액 + 이월 잔량 매수호가 평가액`. 입출금은 손익에서 분리한다. 원가만 저장된 옛 잔량은 새 호가 전까지 원가로 잠정 평가하며 평가시각을 갱신된 것처럼 꾸미지 않는다. 이월·병합은 그 자체로 자본이나 손익을 바꾸지 않는다.

UTC 일일 예산은 현재 W의 1.5%에 당일 실현 및 보유 손실을 반영한다. 진행 캠페인·대기 주문은 추가 계획 손실을 예약한다. 거래 불가능한 잔량은 원금을 무보호 위험으로 예약하되 같은 종목 병합은 병합 후 손절 계획으로 심사한다. 최소 크기 연구의 0.25% W 제한은 **손실 체결 누적액과 예약 위험의 공통 예산**이기도 하므로 단순한 회당 한도로 설명하지 않는다. 추정 켈리 비율이 아니다.

SQLite 한 writer, 제출 전 의도 저장, 누적 체결 차분, 취소 후 재조회, 응답 유실 시 재제출 금지를 유지한다. 엔진 소유 수량만 판다. 계정·외부 주문은 주기적으로 확인하고 후보 사이에는 5초 이내 스냅샷을 재사용한다. 개인 WS의 외부 주문 이벤트는 캐시를 무효화한다. 수수료 0을 확인한 계정만 진입시키며 비용 스트레스는 별도 보고한다.

## 평가와 운영

주 지표는 **잔량 포함 순자산 변화/시간·최대낙폭**, 보조 지표는 실제 체결금액당 손익이다. 캠페인은 시장 경로와 잔량을 공유하므로 독립 표본이 아니다. 대조군은 같은 시각·호가·대기열·비용·지연의 부호 반전과 무조건 대기다. 재생기는 진입 종료와 최종 청산을 분리하고 미청산 자산·회계 오차·데이터 품질·소스/테이프 해시를 출력한다.

`track_c/evaluation-c3.json`은 고정 버전·설정·10개 완전한 KST 일의 평가 창이다. `c3_evidence`는 일별 순자산과 대조군 대비 차이를 2일 블록으로 계산하고 세 비교의 명목 오류율을 보정한다. 짧고 비정상적인 시장에서 이는 근사다. 미완료·코드/설정 변경·시간 불일치·음수 하한은 HOLD, 통과도 REVIEW_ONLY이며 자동 증액하지 않는다. 5일 중 4일 양수는 독립 부호 가정에서도 단측 p=0.1875여서 기존 90% 우위 주장에 충분하지 않다. 결과를 보고 규칙을 고치면 새로운 미래 구간이 필요하다.

엔진이 코인원과 선행 후보를 녹화하며 독립 리더 recorder와 중복 실행하지 않는다. C 원화 알림은 독립 릴레이이며 잔량 포함 W를 쓰고 이월 종료를 완료 승률에 넣지 않는다. 사용자 지시로 매수 진입 알림은 끄고 청산 체결만 발송하며 매수 회계·통계는 유지한다. 배포는 `c3_upgrade`의 준비·flat 전환·워밍업 검증·재개 순서로 설정과 최신 장부를 보존한다. A/B와 학습 worker를 재개하지 않는다.
