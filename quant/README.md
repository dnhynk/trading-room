# Quant pipeline

녹화 → 입력 감사 → 감속 신호 → 기준 정책 → 공유 위험 예산 → 지연·큐·깊이 체결 → 캠페인 장부 → 비용/무작위 비교 → 전방 검증 → 페이퍼 후보.

새 파이프라인은 `quant/`에 있고 기존 `bot/`의 live 실행과 독립적이다. 재생은 표준 라이브러리만 사용한다. 기본 실행은 네트워크·API 키·현재 잔고·운영 params 없이 끝난다. 선택적인 국내 공개 녹화는 `websockets`를 사용한다. 전략 원칙은 [CONCEPT.md](CONCEPT.md), 추출 판단은 [EVIDENCE.md](EVIDENCE.md)에 있다.

실제로 실행한 테스트와 두 개발 구간의 결과는 [VALIDATION.md](VALIDATION.md)에 정리했다.

**현재 제공하는 것은 실행 가능한 연구·페이퍼 파이프라인이다. 수익이 검증된 새 전략이라는 뜻은 아니다.** 기존에 검증한 정책은 기준군으로 동결해 비교한다. 이미 본 자료의 성적만으로 더 복잡한 청산·필터·예측 모델을 채택하지 않는다.

## 바로 실행하기 — 레포 루트, PowerShell

국내 현물과 짧은 청산 후보는 [SCALP.md](SCALP.md)에 전략·대조군·비용 시나리오·실행법을 모았다. `python -m quant compare`가 실제 정책 비교이며, `python -m quant.collect`는 빗썸·코인원·업비트·코빗의 공개 원본/정규화 호가·체결·마감봉·계약 단위를 함께 저장한다. 결과는 연구용 가상 체결이다.

첫 진입 조건 세 개를 분해하고 BTC·ETH와 수집 바구니를 비교하는 실행은 `python -m quant.entry_study --capture <완료된 국내 녹화> --output <새 디렉터리>`다. [실제 96개 대조와 종목별 비용](ENTRY-REVIEW-20260905.md)을 함께 읽는다. 동적 전체 시장 스캐너의 수익 검증이 아니다.

```powershell
# 기존 체결 장부의 높은 승률/음의 손익을 다시 계산한다.
python -m quant audit --until '2026-09-05 12:00:00' --output data/quant/my-audit

# 같은 테이프를 기준 비용과 스트레스 비용으로 한 번에 재생한다.
python -u -m quant replay data/ws/pub-20260904-00.jsonl.gz --output data/quant/my-replay

# 여러 연속 파일. PowerShell의 glob은 명시적으로 확장한다.
$quantTapes = @((Get-ChildItem -Path 'data/ws/pub-20260904-0[0-3].jsonl.gz' | Sort-Object Name).FullName)
python -u -m quant replay @quantTapes --output data/quant/my-panel

python -m unittest quant.test_pipeline
python -m quant trials
```

출력 디렉터리는 매 실행 새 경로를 쓴다. 이미 있는 결과를 덮어쓰지 않는다. 실패도 `data/quant/trials.sqlite`에 남는다. `data/`는 기존 gitignore 대상이다. 같은 설정·테이프·코드를 다시 실행하면 같은 경제적 결과가 나와야 한다(실험 ID·등록 시각은 별도다).

각 재생 결과:

- `manifest.json`: 전체 설정, 코드·테이프·선택적 증거 파일 해시, 실험 등록 내용.
- `events-reference.jsonl`, `events-cost_stress.jsonl`: 예약·주문·취소·부분체결·손절·펀딩·종결 장부.
- `results.json`: 완결과 미완결 캠페인, 비용 포함 현금/평가액, 낙폭, 기대손익, 손익비, 신호 비교, 보류 근거.
- `report.md`: 사람이 읽는 성적표. 미완결과 미관측 비용을 숨기지 않는다.

## 동결된 비교 기준

`configs/reference.json`은 2026-09-05 수정 시점의 신호와 B 위험 프로필을 명시적으로 저장한다. `bot.signal`의 디폴트가 변하면 키 불일치로 실행을 거부하며 조용히 새 디폴트를 섞지 않는다. 모든 실행에 실제 소스 해시도 남긴다.

추출한 것: `Features`, `Strategy`, `sim_match`, `sim_book`, `apply_fill`, `floor_qty`. 원본을 복사해 갈라진 구현 두 개를 유지하지 않는다. `Strategy`는 **재현용 기준 정책**이며 그 안의 모든 경험적 문턱이 수익 알파로 증명되었다는 뜻은 아니다.

이 연구 기본값은 등록된 20개 캐시 계약에 롱·숏 감속 기회를 모두 열어 두고, 대기 주문부터 **전역 캠페인 하나**만 자본을 점유한다. 먼저 관측된 진입에 배정하며 동일 메시지의 동률은 설정의 방향 순서다. AI 국면/헌터의 방향 선정과 롱 급등 목표 매도는 포함하지 않는다. 따라서 **기존 Track B 전체의 재현 성적과 직접 비교하지 않는다**. 방향 선정 효과를 제거한 감속 기준군이고, 그 변형 자체의 수익 우위도 미입증이다. 현재 소스의 정확한 B 회귀 비교는 기존 `bot.replay_b`가 맡는다.

위험은 현행 B의 0.75W 명목, 0.05W 기본 스탑 예산, 15ATR1m 최소 거리, 한 유닛·공유 풀 하나, UTC 0.15W 일일 예산과 최대 스탑 3회 이내다. 수량은 계약 단위로 내리며 호가 가격에서도 명목 상한을 확인한다. 다음 캠페인은 새 자본으로 다시 계산하고 대기/진행 중 캠페인은 수량 기준을 고정한다. 이는 최적 위험이라는 주장이 아니다.

수수료 2/6bp, 지연 1초, 추가 실행비용 5bp는 **동결한 시나리오**이며 현재 계정의 정확한 요율이라는 뜻이 아니다. 스트레스는 수수료 2배·추가 25bp·지연 2배다. 큐는 기존 보정 모델, 시장가 청산은 L15 깊이를 소비한다. 부족한 깊이를 무한 유동성으로 채우지 않고 다음 호가를 기다리며 품질 경고를 남긴다. 취소 지연 중에는 기존 주문이 체결될 수 있다. 수신 시각을 기준으로 처리하므로 미래 채널 정보를 과거 초에 정렬해 넣지 않는다.

## 진입의 알파를 별도로 읽기

성적표의 `entry_study`는 속도 감속 + 공격 체결 반전 + 거래량 감쇠를 충족한 신호를 15분 고정 지평에서 측정한다. 진입 지연 뒤 최초의 관측 호가로 들어가고 실제 시각으로 15분 뒤 청산 호가를 찾는다. 초 인덱스 900개를 15분으로 착각하지 않는다. 결측 경로와 미완성 지평은 검열 수에 남긴다.

신호와 무작위 기준은 같은 날짜·종목·방향에서 개수를 맞춘다. 두 그룹 각각의 창은 겹치지 않게 잡지만 그룹 사이와 종목 사이는 상관될 수 있으므로 날짜 전체를 묶는다. 이 표는 양쪽 시장가 비용을 적용한 **타이밍 진단**이며 maker 정책의 실제 수익·독립 반복 실험·무작위 진입 포트폴리오가 아니다. 단일 시드의 우위나 작은 표본만으로 진입 알파를 확정하지 않는다. 펀딩은 이 진단에서 제외된다.

## 전방 검증과 에피소드 경계

```powershell
# 실제 미래 시각을 명시한다. 과거 창이나 이미 등록한 창과 겹치면 거부한다.
python -m quant register --start '2026-09-10T00:00:00+09:00' --end '2026-10-10T00:00:00+09:00'

# 기간 종료 후 반환된 ID를 사용한다. 실행 중 코드/설정을 바꾸면 소비된 실패 시도로 남는다.
python -m quant replay @quantTapes --trial <등록_ID> --output data/quant/forward-run

# episode JSON은 [{"episode":"id","start":"...+00:00","end":"...+00:00"}, ...]
python -m quant folds --episodes episodes.json --train-end '2026-09-10T00:00:00Z' --validation-start '2026-09-11T00:00:00Z' --validation-end '2026-10-10T00:00:00Z' --embargo-s 900 --output folds.json
```

마지막 예의 날짜는 사용법 예시다. 이 세션이 미래 실험을 자동 등록하거나 일정을 예약하지 않는다. 학습 창과 검증 창을 모두 건드리는 에피소드는 통째로 제외 목록에 들어간다. 같은 코인의 같은 펌프를 자정에서 둘로 나누지 않는다. 실제 에피소드 ID는 원본 시장 사건에 근거해 외부에서 부여한다.

기본 문턱 20일·100캠페인·20에피소드는 연구 운영 최소치다. 통계적 충분성을 보증하지 않는다. 개발 여부, 입력 품질, 전체 유니버스 범위, 펀딩 귀속, 미완결, 비용 스트레스, 양의 날짜/에피소드 블록 하한, 무작위 타이밍 비교, 로그 성장과 낙폭을 함께 검사한다. `HOLD` 사유를 하나씩 공개하며 통과 결과도 `PAPER_CANDIDATE`다. 실거래 적용 명령은 없다.

## 비용·전체 기회·에피소드 자료

누락된 항목을 boolean 한 줄로 통과시키지 않는다. `replay --funding F --universe U --episodes E`로 증거 파일을 제공하며 모두 해시에 포함한다.

펀딩 파일은 실제 정산 시각의 요율(소수)·mark·커버 범위를 담는다. ticker의 다음 정산 예상 요율을 확정 정산으로 바꾸지 않는다.

```json
{"source":"exchange settlement export", "coverage_start":"2026-09-04T00:00:00Z", "coverage_end":"2026-09-05T00:00:00Z", "symbols":["MAGMAUSDT"], "settlements":[{"t":"2026-09-04T08:00:00Z", "symbol":"MAGMAUSDT", "rate":0.0001, "mark":0.26}]}
```

유니버스는 당시 거래 가능 집합을 얻은 독립 자료의 출처와 시간 구간별 심볼을 담는다. 코드가 설정 계약, 모든 구간, 각 심볼의 실제 호가 공백을 대조한다. 이미 거래한 코인만 목록에 써도 전체 거래소 집합이라는 증명이 생기지는 않는다. 출처의 경제적 완전성은 여전히 감사 대상이다.

```json
{"source":"dated exchange universe snapshot", "intervals":[{"start":"2026-09-04T00:00:00Z", "end":"2026-09-04T01:00:00Z", "symbols":["MAGMAUSDT"]}]}
```

에피소드 파일은 전체 보유 경로가 한 에피소드에 속하는지 검사한다. 겹치는 ID나 소속 불명 캠페인은 보류한다. 같은 ID는 날짜나 심볼이 달라도 하나의 블록으로 집계한다.

```json
{"source":"frozen episode attribution protocol", "episodes":[{"id":"episode-001", "symbol":"MAGMAUSDT", "start":"2026-09-03T00:00:00Z", "end":"2026-09-05T00:00:00Z"}]}
```

## 페이퍼 운용

```powershell
python -u -m quant paper --tape data/ws/pub-20260905-05.jsonl --seconds 60 --output data/quant/paper-check
```

실제 커지고 있는 현재 `.jsonl` 경로를 지정한다. 시작 이전 부분은 신호 워밍업에만 쓰고 시작 이후 5초 이내의 새 데이터에서만 가상 진입한다. 재생과 동일한 `Engine.process`를 쓰며 거래소 연결은 없다. 결과는 `paper.json`과 가상 주문 장부에 남는다.

각 호출은 독립된 가상 계좌다. 이전 세션의 가상 포지션을 이어받는 장기 운용 데몬은 아니다. 지정한 파일의 교체/절단은 오류이며 시간별 녹화 파일 전환은 새 세션으로 시작한다. 종료 시 열린 포지션은 임의 전량 청산하거나 승리로 처리하지 않는다. 펀딩 정산을 연결하지 않은 페이퍼 결과는 승격 증거가 될 수 없다.

## 운영 경계

기존 params·제어 파일·감시견·자식 엔진·사용자 포지션·거래소 스탑·Slack 릴레이를 조작하지 않는다. 연구 결과를 live에 넣는 단계는 해당 기간 검증과 감독의 운영 계약을 별도로 충족해야 한다. 이 파이프라인은 아직 입증되지 않은 수익을 만들어 냈다고 주장하기 위해 위험을 늘리지 않는다.
