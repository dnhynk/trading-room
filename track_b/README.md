# Track B — 작전코인 캠페인

공개 설정은 정지·dry 모드다. `config/tracks.json`의 B 상태와 운영자가 설정한 `STOP`·`PAUSE`를 임의로 해제하지 않는다. 설정은 `config/bitget.json`의 `hunt`와 `hunt.strat`이며 B 분석에는 `hunt.on=1`인 별도 프로필이 필요하다. AI 호출은 예시 설정에서 꺼져 있다. A/B는 계정과 실행 엔진을 공유하지만 B의 전략은 독립 계약이다.

거래대금·변동·펀딩·현물 시장과 국면의 발자국으로 살아 있는 에피소드를 찾고, 확인된 감속에서 캠페인을 시작한다. 자격은 보유 여부를, 순위는 빈자리를 채우는 순서를 결정한다. 이미 든 종목을 순위 때문에 갈아치우지 않는다. 여러 기회를 관찰해도 자본은 기존 풀의 선착순 소유권으로 제한한다.

현재 비교 기준은 1유닛·풀 1과 자본 비례 손실 예산이다. 기본 돈 스탑은 평단에서 유닛당 한도/기준 유닛 수량만큼 떨어진다. 유닛 수만으로 거리를 조이지 않으며, 명목 예산이 실제 최악 체결손실을 보장하지 않는다. ATR 거리 부족은 수량을 줄여 해결한다. 수량은 위험 상한 아래로 내리고 최소 단위를 감당하지 못하면 진입하지 않는다. 거래소 보호 주문과 일일 손절·손실 한도는 풀 전체에 적용한다.

프로세스 종료·임대 만료·읽기 실패를 빈 자본으로 해석하지 않는다. 다른 책의 보유와 미결 주문을 확인하기 전 새 캠페인을 열지 않는다. 독립 관측 단위는 flat→첫 체결→flat 캠페인이다. 부분체결은 새 표본이 아니며 미완결·누락·수동 종료를 평가에서 조용히 제외하지 않는다.

AI 국면 판독은 예정된 판독 횟수의 과반이 합의할 때만 규칙을 대체한다. 실패 호출을 분모에서 빼지 않고 합의가 없으면 규칙으로 돌아간다. 스캔 중 설정이 바뀌면 오래된 결정을 적용하지 않는다. 합의율이나 스캔 종가 경로를 실제 적중률·실거래 손절률로 해석하지 않는다.

| 코드 | 역할 |
|---|---|
| `hunt.py`, `whale.py` | 자격·국면 판독·캠페인 후보 선정 |
| `campaigns.py`, `phases.py` | 과거 스캔과 국면 경로 연구 |
| `research.py`, `replay.py` | 캠페인 장부 감사와 동일 비용·기회·자본 비교 |
| `common/cycle.py`, `common/risk.py` | 공유 실행, 자본 풀·누적 손실·보호 주문 |

`python -m unittest discover -s tests/b -t .`로 B 검증을 실행한다. 개선 채택은 날짜·종목·독립 에피소드와 비용 스트레스, 시간순 검증으로 판단한다. 이미 본 구간은 개발용이며 표본 부족을 이유로 위험을 늘리거나 자동 적용하지 않는다. 공개본에는 실제 캠페인 장부나 과거 운영 Git 이력을 포함하지 않는다.
