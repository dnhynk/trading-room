# Track A — 순환매

현재 사용자 지시로 정지 중이다. `config/tracks.json`의 A 상태와 루트 `STOP`·`PAUSE`를 임의로 해제하지 않는다. 설정은 `config/bitget.json`이며 A는 `hunt.on=0` 경로다. A/B는 계정과 공통 실행 엔진을 공유하므로 둘을 동시에 재개하지 않는다.

반대 방향 움직임의 감속에 담고, 유리한 움직임의 정체에 덜어 평단과 실현손익을 순환시킨다. 롱·숏은 대칭이다. 추가는 직전 매수보다 유리한 사다리 위치의 감속에서만 하고, 덜기는 새 로트의 원가 및 왕복 비용 조건을 지킨다. 마지막 물량도 정체에서 정리할 수 있다. 감속 없는 추가는 하지 않는다.

종목은 통행료를 감당하고 충분한 사이클을 만드는 바구니다. 순위는 빈자리를 채우는 데 사용하며 이미 보유한 책의 교체 사유가 아니다. 자격을 잃으면 담기를 멈추고 기존 청산 규칙으로 비운 뒤 뺀다. 균등 비중이 기본이며 비중 변경에는 같은 시각의 실거래 비교가 필요하다.

거래소의 자본 비례 돈 한도 스탑과 일일 손실 상한을 유지한다. 미결 주문·보유·다른 책의 상태를 확인할 수 없으면 새 위험을 열지 않는다. 실현손익·수수료·부분체결·자본 이동을 구분한다. 손실 중 약반등에서 노출을 줄이는 실험 기능은 기존 설정에서 꺼져 있으며 이 정리로 재활성화하지 않았다.

| 코드 | 역할 |
|---|---|
| `select.py`, `scan.py` | 바구니 자격·선정·wind_down |
| `cycles.py` | 실제 체결로 재구성한 사이클 통계 |
| `backtest.py`, `replay.py`, `tune.py` | 재생·시간순 비교·명시적 수치 실험 |
| `capture.py`, `recon.py`, `legs.py`, `pair.py`, `slip.py`, `sweeps.py` | 체결·가격 경로 분석 |
| `common/signal.py`, `common/cycle.py` | A/B 공통 신호·주문·보유 실행 |

`python -m unittest tests.common.test_signal tests.common.test_cycle tests.a.test_select`로 핵심 회귀를 실행한다. 기준 테이프는 외부 상태 디렉터리의 `data/ws/pub-20260829-0[4-6].jsonl.gz`이며 `python -m track_a.backtest <테이프 경로>`로 재생한다. 이미 본 테이프의 결과는 개발 검증이다. 문턱·위험·운영 설정은 이번 구조 정리에서 바꾸지 않았다.
